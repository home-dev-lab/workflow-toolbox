# Memory hygiene

The auto-loaded index has a SILENT ceiling: measure both ENTRY COUNT and SIZE limits, and check
both directions: every disk fact is reachable AND every index/hub reference resolves; a deliberate
de-indexing (retraction kept so old references resolve) is fine. Neither a healthy entry count nor
a small file proves the other.
Under hubs, budget index lines, not per-line width. Route a behavior-changing correction to a RULE
in the same pass as recording it; a note body is recall-on-demand, not an always-loaded correction.
A rule is a pure directive. Rationale/field cases are not kept beside a rule, and no pointer leads to them.
State the operative principle and the invariant that makes it right — no narrative, incident stories,
dated banners.
The repository history is the record; rewrite the rule in place instead of stacking a chronicle.
On memory, index, hub, archive, or rule writes, apply the memory-hygiene at-act companion.
